- 2026-10-21 — Tubulin tree (`scripts/tubulin_tree.py`, rule `tubulin_tree`): Od δ and ε fall inside the δ (97.5/99) and ε (100/100) reference clades; the ζ clade (99/100, 17 sequences including ζ from amphioxus ×2, Clavelina, Ciona ×2, Phallusia, Botryllus, Styela clava, Thalia democratica) contains no Oikopleura sequence. ζ-tubulin is therefore lost on the Oikopleura branch and retained across the other tunicates sampled; δ and ε are retained. - 2026-10-20 — RBH is reciprocal against the FULL anchor-species proteome, not the 272 anchors. The first implementation ran easy-rbh anchors-vs-proteome, so a target protein only had to prefer one listed anchor over the other 271; paralogs outside the list (CDC20 for CDC20B, CDC20/FZR1 for CDC20B, TUBG1/2, cyclins, E2Fs) could pass as the listed gene, and the same flaw seeded profiles with paralogs (fly fzy would seed CDC20B). `rbh.py` and `seeds_collect.py` now run easy-rbh of the whole human (or Xenopus, for TUBZ1) reference proteome against each target proteome and keep hits whose reciprocal best is the anchor itself (`common.rbh_full_proteome`). Seeds and profiles were rebuilt; proteome searches rerun.
- 2026-10-20 — Profile hits are credited to the profile that scores the target best ("owner"). Tubulin, cyclin and E2F profiles cross-hit the whole family (in the Augustus proteomes the best TUBE1/TUBD1 "hits" were β-tubulins while miniprot showed the true ε and δ loci in the genome). The checkpoint reports cross-hits separately; the same rule goes into `tiers.py` before the matrix is built.
- 2026-10-20 — A provisional `HMM-partial` class (E ≤ 1e-10 with profile coverage below 0.5) is reported in the checkpoint because long coiled-coil proteins (CEP192, PCM1, CDK5RAP2, CEP128, NPHP3, GLI1, TUBGCP6…) reach E ≤ 1e-40 in *Ciona* and the Od lineages with 10–40% profile coverage. Whether such hits earn E2 is a threshold decision for TS (`config/params.yaml`); nothing in the matrix changes until then.

- 2026-10-20 — Proteomes for Osaka, Barcelona, Kume and Aomori are the longest-isoform Augustus models from the Plessy 2024 Zenodo supplement (`AugustusAnnotation.tar.gz`: OSKA2016v1.9.sm, Bar2_p4_Flye.sm, KUM-M3-7f.sm.OKI-CDS, AOM-5-5f.sm.OSKA-CDS; 14–17k proteins, mean ~460 aa). The same archive holds Augustus runs for the six Naville 2019 larvacean genomes; those are used as uncurated proteomes for Oalb, Olon, Ovan, Bsty, Mery, Fbor (the larger `cionamodel` run where one exists) so hmmsearch can see predicted proteins, while the miniprot genome search stays mandatory for any absence. Their short mean lengths (146–350 aa) reflect genome fragmentation, so E1/E2 recovery in these species will understate presence.
